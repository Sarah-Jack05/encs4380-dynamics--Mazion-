My System: Micromouse Motor Speed Control

Applying PID control to regulate the speed of the MAZION Micromouse DC motors using a first-order plant model and digital feedback control.

1. Project Overview

MAZION is an intelligent Micromouse robot designed to solve an unknown maze using sensors, algorithms, and intelligent decision-making. Accurate motor speed control is important for smooth movement, reliable navigation, and reducing positioning errors.

In this part, we apply a PID controller to regulate the speed of the robot's DC motors. The controller compares the desired motor speed with the measured speed and adjusts the PWM command sent to the motor driver.

Control objective: Maintain the motor speed close to the reference speed while keeping the PWM command within the allowed range of 0–100%.

Each motor can be controlled independently using its encoder feedback. The same control approach can be applied to both wheels.

2. Hardware and Motor Driver

The motor driver selected for the Micromouse project is the TB6612FNG, a dual DC motor driver manufactured by Toshiba. It allows the microcontroller to control the direction and speed of two DC motors.

  • PWM: Controls the motor drive level through pulse-width modulation.
  • IN1 and IN2: Select the motor operating direction.
  • STBY: Enables or disables the motor driver.
  • VCC: Supplies the logic circuit.
  • VM: Supplies the motor power.

The TB6612FNG is a motor driver, not the motor itself. Therefore, the plant parameters in this simulation describe the assumed DC motor model and are not specifications of the TB6612FNG.

Feedback sensor: The motor encoder provides measurements of wheel rotation. These measurements are used to estimate the actual motor speed and calculate the controller error.

3. Plant Model and Parameters

For the initial controller design, the DC motor is approximated as a first-order system:

$$G(s)=\frac{K}{\tau s+1}$$

Where:

  • K: Steady-state gain of the motor model.
  • τ: Motor time constant.
  • u(t): PWM command.
  • y(t): Motor speed in mm/s.

The following values are currently used as assumed simulation parameters:

Parameter Value Description
K 2.0 Assumed motor gain
τ 0.10 s Assumed time constant
Input 0–100% PWM command
Output mm/s Motor speed

With the assumed gain K = 2.0, a 1% PWM command corresponds to a steady-state speed of approximately 2 mm/s in this model.

Parameter source and limitation: These values are assumed simulation parameters. They have not yet been identified experimentally from the actual Micromouse motors. The final values should be obtained from a PWM step test using encoder measurements.

How will we identify the motor parameters?

  1. Apply a fixed PWM command to the motor.
  2. Record the encoder readings over time.
  3. Convert encoder counts into wheel speed.
  4. Estimate the final steady-state speed.
  5. Calculate K from the steady-state speed and PWM input.
  6. Estimate τ from the time required to reach 63.2% of the final speed change.

5. PID Controller Design

The PID controller adjusts the motor input according to the difference between the reference speed and the measured speed.

$$e(t)=r(t)-y(t)$$ $$u(t)=K_p e(t)+K_i\int e(t)\,dt+ K_d\frac{de(t)}{dt}$$

The controller gains currently used in the simulation are:

Gain Value Function
Kp 1.2 Responds to the current error
Ki 4.0 Reduces steady-state error
Kd 0.01 Responds to the rate of error change

The proportional term improves the response speed, the integral term reduces the remaining steady-state error, and the derivative term provides additional damping depending on the system response.

Controller design status: These are the current simulation gains, not yet experimentally validated final gains. The damping ratio and all performance requirements must be checked using the actual controller model.

6. Digital PID Implementation

In the physical Micromouse, the controller will execute periodically on the microcontroller. The control signal is calculated using the discrete-time PID equation:

$$u[k]=K_p e[k]+K_iT_s\sum_{j=0}^{k}e[j]$$ $$+K_d\frac{e[k]-e[k-1]}{T_s}$$

Where Ts represents the sampling interval and k represents the current sample.

Control sequence

  1. Read the motor encoder counts.
  2. Calculate the actual wheel speed.
  3. Calculate the error between reference and measured speed.
  4. Update the proportional, integral, and derivative terms.
  5. Calculate the requested control signal.
  6. Apply PWM saturation and anti-windup protection.
  7. Send the PWM command to the TB6612FNG.
  8. Repeat the process at the next sampling interval.

PWM Saturation

The PWM command must remain within the physical range of 0% to 100%. Therefore, the controller output is limited before it is sent to the motor driver.

$$u_{\text{PWM}}=\min(100,\max(0,u))$$

Anti-Windup

When the PWM output reaches its limit, the integral term may continue accumulating error. This can cause integral windup and a delayed recovery after saturation.

An anti-windup mechanism is used to prevent unnecessary accumulation of the integral term while the actuator is saturated.

Implementation status: The current results are based on Python simulation. Physical implementation requires the actual motor connections, encoder configuration, microcontroller pins, and periodic control loop.

9. Limitations and Future Work

The current model is a simplified representation of the motor dynamics. It does not fully represent all physical effects that may influence the Micromouse movement.

  • Motor parameter identification using an encoder-based PWM step test.
  • Testing both motors independently.
  • Considering load variations and wheel friction.
  • Checking the effect of battery voltage changes.
  • Verifying the controller on the physical robot.
  • Comparing simulated and measured motor speed responses.

10. Conclusion

This application demonstrates how PID feedback control can regulate the speed of a Micromouse DC motor. A first-order plant model is used to study the motor response and evaluate the controller performance.

The simulation provides an initial step toward implementing closed-loop motor speed control in MAZION. The next step is to identify the actual motor parameters using encoder measurements, verify the control specifications, and test the controller on the physical robot.

Final objective: Achieve reliable and repeatable motor speed control to support accurate straight-line movement and turning during maze navigation.
